Le Cinq — Light & Minimal Template
---------------------------------
This package contains a modern, responsive two-page static site ready for GitHub upload.
Replace the placeholder 3D files with your own .glb and .usdz files for AR functionality.

Files included:
- index.html (Accueil)
- menu.html (Menu)
- css/style.css (styles, animations)
- js/main.js (helpers)
- assets/logo-round.svg (round logo icon)
- assets/favicon.svg (favicon)
- assets/text-logo.svg (integrated SVG logo)
- assets/placeholder.glb and assets/placeholder.usdz (dummy files; replace before production)
- le_cinq_modern.zip (this package)

Deployment notes:
- Upload the folder contents to your GitHub repo (root) or to Cloudflare Pages/GitHub Pages.
- For iOS Quick Look, ensure .usdz files are accessible via direct links and referenced via ios-src in <model-viewer>.
- For Android, model-viewer will attempt Scene Viewer / WebXR. Behavior varies by device/browser.

Need help replacing the 3D files, adding more dishes, or deploying to GitHub? Tell me and I'll update the package.
