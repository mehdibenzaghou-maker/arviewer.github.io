# Seb's Garden Restaurant Website

A modern restaurant website featuring interactive 3D menus and AR experiences.

## Features

- 🍽️ Interactive 3D menu with Google Model Viewer
- 📱 Augmented Reality (AR) support for dish viewing
- 🎨 Modern dark blue and gold design
- 📱 Fully responsive design
- ⚡ Fast loading with Cloudflare backend
